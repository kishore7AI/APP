# NxtLearnn — Full-Stack Course Platform

## Architecture
- **Frontend**: React + Vite (JavaScript) + Tailwind CSS + Lucide React
- **Backend**: Python + FastAPI + SQLAlchemy 2.0 (Async) + asyncpg
- **Database**: Neon (Serverless PostgreSQL)
- **Auth**: FastAPI JWT + Google OAuth2
- **Video & Media**: ImageKit (Signed HLS Adaptive Bitrate Streaming)
- **Payments**: Polar (Subscriptions, Single Courses & Lifetime access via HMAC Webhooks)
